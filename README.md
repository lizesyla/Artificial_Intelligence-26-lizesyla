# Artificial Intelligence 2026 — Lizë Syla

Detyrat semestrale për lëndën **Inteligjenca Artificiale**, të implementuara në Python 3. Secila detyrë ka dosjen e vet, dhe brenda saj secila pjesë ka kodin, testet, raportin dhe rezultatet.

| Detyra | Tema | Dosja | Afati |
|---|---|---|---|
| 1 | Teknikat e painformuara të kërkimit (*Uninformed Search*) | [`detyra1/`](detyra1/) | dorëzuar |
| 2 | Kërkimi i informuar (A*), SAT, Constraint Programming, Metaheuristika | [`detyra2/`](detyra2/) | 3 Dhjetor 2026 |

